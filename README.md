# SeaSky Penthouse — Brochure

A **6-page, print-ready HTML brochure** for **SeaSky Penthouse**, a luxury apartment on the 12th floor overlooking the Black Sea in Burgas, Bulgaria.

## Pages

| # | Title | Description |
|---|-------|-------------|
| 1 | **Cover** | Hero photo with panoramic sea view, welcome text, QR codes for direct booking, Booking.com, and Airbnb |
| 2 | **Interior A** | Olive/cream split layout showcasing the apartment interior with three article columns |
| 3 | **Interior B** | Luxury travel theme with resort-style text columns and article teasers |
| 4 | **Back Cover** | Polaroid-style photo clothesline, contact details, phone, and website |
| 5 | **Smart Home** | Alexa voice commands, room-by-room button controls (Living Room, Bedroom, Kitchen) |
| 6 | **Parking & Check-in** | Step-by-step arrival guide, key info, and Google Review QR code |

## Features

- **Print-ready** — A4 portrait, `@page` rules, automatic page breaks
- **Self-contained** — single HTML file, no build step
- **Responsive for print** — screen preview with shadow, clean print output
- **Embedded QR codes** — base64-encoded PNGs for booking platforms
- **SVG decorations** — torn-edge dividers, sun logo, wave separators
- **Google Fonts** — Playfair Display + Open Sans

## Usage

Open `index.html` in any modern browser. To print:

1. Open the file in Chrome / Edge
2. Press `Ctrl + P` (or `Cmd + P` on Mac)
3. Set paper size to **A4**, margins to **None**
4. Enable **Background graphics**
5. Print or save as PDF
